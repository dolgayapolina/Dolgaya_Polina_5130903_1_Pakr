Задание Правила Игровое поле
  • на одной картинке может быть разный фон, текст, и цвет текста
  • найти пару по какому-то признаку, слова с определенной буквой
  • на картинках части речи
  • слова с перепутанными буквами

Правила игры

Уровень 1 — по СМЫСЛУ. Смотри на то, что написано на карточке. «КРАСНЫЙ» — в ящик «Красный», цвет букв игнорируй.

Уровень 2 — по ЦВЕТУ БУКВ. Теперь смотри только на цвет шрифта: «КРАСНЫЙ» синими буквами — в ящик «Синий».

Уровень 3 — по ЦВЕТУ ФОНА. Смотри только на фон карточки: «ЗЕЛЁНЫЙ» на синем фоне — в ящик «Синий».

Кликни по карточке, чтобы переложить её в ящик. Кликни по карточке внутри ящика — она вернётся на поле. Когда всё разложишь — жми «Проверка».
